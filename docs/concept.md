**Концепция**: сервис, который обрабатывает систему заказов и их оплаты.

**Основные сущности**:
* User - пользователь
* Order - заказ
* Product - товар
* Item - товар в заказе
* Reservation - бронь

**Основные usecases + бизнес-процессы**:
* Создать заказ: сформировать заказ, зарезервировать товар.
* Оплатить заказ: создать платеж, завершить заказ.
